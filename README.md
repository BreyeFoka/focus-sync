# FocusSync

**Live:** [focussync.breyefoka.dev](https://focussync.breyefoka.dev)

A Pomodoro focus app: a work/break timer, a task list for the session, and ambient sounds to work to.

## Features

- Focus timer with work and break intervals
- Task list for what you plan to finish in the session
- Ambient sound player with volume control
- Light and dark themes

## Run it

```bash
npm install
npm run dev     # http://localhost:3000
```

## Checks

GitHub Actions installs dependencies and runs the production build (which type-checks) on every push. There are no unit tests yet.

Built with Next.js, TypeScript, Tailwind CSS, Radix UI and Framer Motion.
